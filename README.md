# TubeFolio

YouTubeの登録チャンネルをフォルダ分けするChrome拡張（PocketTube風の自作版）。

## インストール / 更新
1. zipを展開（更新時は前のフォルダに上書き）
2. `chrome://extensions` → デベロッパーモードON →「パッケージ化されていない拡張機能を読み込む」
   （更新時は拡張機能カードの ⟳ ボタン）
3. YouTubeのタブを再読み込み

## 使い方
- 左サイドバー（登録チャンネルの上）
  - **動画 / ライブ・配信 / ショート**：登録チャンネルの一覧を種類別に表示
  - **フォルダ**：クリックでそのフォルダだけに絞り込み（もう一度で解除）。▸で開閉
  - **フォルダ設定**：管理画面を開く
- 登録チャンネル画面の上部：フォルダ切り替え、種類の切り替え、列数（3/4/5）
- フォルダ設定
  - 「登録チャンネルを読み込む」で今の登録チャンネルを一括取り込み
  - フォルダはドラッグで並べ替え／他フォルダの中へ（上端・下端＝前後、中央＝中に入れる）
  - チャンネル行をフォルダへドラッグして追加（チェックで複数まとめて）
  - 色の四角をクリックでカラーパレット、＋でサブフォルダ、✎で名前変更
  - 「登録済み ▾」から通知設定の変更・登録解除。解除後は「チャンネル登録」で再登録
  - 変更は自動保存

## 仕組み・制限
- 一覧は各チャンネルの「動画 / ライブ / ショート」タブをYouTube内部APIで並列取得し、揃ってから一括表示（RSSは予備）。10分キャッシュ
- サムネイルの枠：登録チャンネル＝青、未登録（解除済み含む）＝赤。ホーム・検索・おすすめ欄にも表示
- ショートは投稿日時が取れないため、各チャンネルの新しい順に交互に並ぶ
- 「すべて」で150チャンネル超のときは、直近60日に投稿のある（または未取得の）チャンネル最大400件に絞って取得
- 「ライブ・配信」は配信中・配信予定・アーカイブを表示
- 動画クリックは通常のページ遷移（YouTube標準より少し遅い）
- データは `chrome.storage.local`（このPCのみ）

## バックアップ・同期（v3.2）
フォルダ設定 →「バックアップ・同期」
- エクスポート：設定一式をJSONでダウンロード／インポート：JSONから復元（置き換え）
- データ量の目安：900チャンネルで約380KB（うち更新情報 約84KB）

### Google Drive の準備（最初の1回だけ）
1. https://console.cloud.google.com/ でプロジェクトを作成（既存でも可）
2. 「APIとサービス」→「ライブラリ」で **Google Drive API** を有効化
3. 「OAuth同意画面」を作成（外部・テストユーザーに自分のGoogleアカウントを追加）
4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類 **ウェブアプリケーション**
   - 「承認済みのリダイレクトURI」に、バックアップ・同期パネルに表示されるURI（https://＜拡張ID＞.chromiumapp.org/）を追加
5. 作成されたクライアントIDをパネルに貼り付けて保存 →「Google Drive に接続」

- 保存先：マイドライブ直下の `TubeFolio-sync.json`（この拡張が作ったファイルにしかアクセスしない権限）
- 自動同期ON：フォルダ設定が変わると約5秒後に保存。YouTubeを開いたとき、Driveの方が新しければ取り込み
- 拡張機能のフォルダの場所を変えるとIDが変わるので、リダイレクトURIの登録をやり直す
